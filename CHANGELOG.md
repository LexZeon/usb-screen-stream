# Changelog

All notable changes to this project will be documented in this file.

## v1.0.0 - 2026-09-02

Initial open-source release.

- Added Android MediaProjection screen capture app.
- Added Android foreground streaming service.
- Added USB transport through `adb forward`.
- Added low-latency MJPEG frame streaming protocol.
- Added Windows WinForms viewer with connection controls and display options.
- Added bundled Windows release package layout with ADB platform-tools support.
- Added troubleshooting notes for ADB authorization and Huawei PrivateSpace.
- Added open-source documentation, MIT license, contribution guide, changelog, security policy, and third-party notices.
